Tracking IDs

GA4, Meta Pixel and Clarity should normally be deployed/managed through GTM when that is your chosen architecture. This page only stores the IDs for your content/configuration; create and publish the actual tags in GTM.

Optional direct GitHub publisher

This can update content.json using the GitHub Contents API. The token is kept only in memory and is never written to content.json. Prefer a fine-grained token restricted to one repository with only the minimum Contents permission required.

Never paste a GitHub token into index.html, app.js, content.json or any public repository file. Anyone who can read the repository could steal it.
